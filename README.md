# Morgan Stanley Banking Data Analysis

## Project Overview

This project analyzes Morgan Stanley banking data using Python to understand customer transactions, account balances, risk scores, and credit ratings.

The analysis focuses on identifying useful patterns in customer financial data and generating business insights.

## Objective

The main objectives of this project are:

- Analyze customer transactions
- Study account balances
- Analyze customer risk scores
- Understand credit ratings
- Identify financial patterns
- Generate useful business insights

## Dataset

The dataset contains banking-related customer information such as:

- Customer transactions
- Account balance
- Risk score
- Credit rating
- Transaction date
- Other customer financial attributes

Dataset file:

`morgan_stanley.csv`
